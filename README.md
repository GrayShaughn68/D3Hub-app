## Run the website locally

The current website is a static frontend and does not need a build step or package installation.

1. Open a terminal in this folder.
2. Start a local web server:

   ```powershell
   py -m http.server 8000
   ```

   If `py` is unavailable but Python is installed, use `python -m http.server 8000`.
3. Open [http://localhost:8000](http://localhost:8000) in a browser.
4. Stop the server with `Ctrl+C` in the terminal.

Rankings, records, schedules, and scores are currently illustrative demo data; a verified Division III data source has not been connected.
